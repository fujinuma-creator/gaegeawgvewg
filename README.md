# KOTOBA — 英語（Xcode / SwiftUI）

広東語版アプリ（Lingro）と同じ画面構成・デザイン・仕様で作った、日本人向けの英語学習 iOS アプリです。
手描き風のカードと斜線の空の背景、緑のボタン、4段階の復習（1日後 → 1週間後 → 2週間後 → 1ヶ月後）をそのまま実装しています。違うのは中身（英単語・例文・会話・発音・文法）だけです。

## 画面

| # | 画面 | 内容 |
|:-:|:-|:-|
| 1 | ホーム | 日付と一言、継続学習日数・本日の学習時間・1週間のチェック、学習メニュー（全単語リスト／復習リスト／発音／文法）、日常のトピック会話 |
| 2 | 全単語 | 検索、すべて／チェック、並び替え（シャッフル・会話頻度順・ABC順 …）、「今日の100語」、単語カードの展開（英語の定義・使う場面・例文・関連表現）、「＋ 新しい例文を生成」、チェックした語の復習 |
| 3 | 復習リスト | 今日の復習（段階ごとの数）、カレンダー（日ごとの復習数）、選んだ日のリスト、「今日のN語を復習する」 |
| 4 | フラッシュカード | 表 → 答え → 詳しく の3段階タップ、英語→日本語／日本語→英語の切り替え、右スワイプ「思い出せた」／左スワイプ「思い出せなかった」 |
| 5 | 発音 | イギリス英語 44 音（母音 12・二重母音 8・子音 24）のタイルと、選んだ音の「口の形・コツ・注意点」（日本語）、単語帳から集めたその音の単語 |
| 6 | 文法 | 入門／初級／中級／上級、番号つきの項目を開くと解説（色分けブロック・例文と発音記号・見分け方・×○）、4択の練習問題（379問・日替わり10問） |
| 7 | トピック会話（一覧） | 検索、カテゴリ（17）・レベルの絞り込み、続きから、カテゴリ別リスト、カテゴリのグリッド |
| 8 | トピック会話（会話） | A／B の吹き出し（日本語・英語・読み上げ）、場面の切り替わりは点線、この会話の表現、次の会話 |
| 9 | 設定 | 英語の種類（アメリカ／イギリス／イギリス Posh／オーストラリア／インド／アイルランド／スコットランド／南アフリカ）・読み上げの速さ・自動読み上げ、AI（Claude／OpenAI／Gemini）のAPIキーと接続テスト、例文の数・くだけ具合、1日の復習の上限、復習の通知、バックアップ、CSV書き出し、学習記録のリセット |

読み上げは同じボタンを2回続けて押すと 0.25 倍速、3回目で元の速さに戻ります。

## 起動方法（ターミナル）

```bash
cd ~/Projects/gaegeawgvewg
git pull --rebase origin claude/english-vocab-app-YCZhY
open EnglishVocabApp/EnglishVocabApp.xcodeproj
```

Xcode が開いたら **EnglishVocabApp → Signing & Capabilities → Team** で自分の Apple ID を選び、▶ で実行します。
Node.js や CocoaPods は使いません。

> 🔊 声が機械的に聞こえる場合は、iPhone の「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語」から「拡張」「プレミアム」の声をダウンロードしてください。

## データの場所

| ファイル | 内容 |
|:-|:-|
| `SeedData.swift` | 単語（4,000 語以上。英語・発音記号・日本語・英語の定義・使う場面・例文）、会話頻度リスト 3,000 語、トピック会話 857 本、例文の発音記号、発音の 44 音 |
| `SeedWords.swift` | 単語に進捗保存用の固定 id を付ける |
| `PronunciationSeed.swift` | 発音タイル（44 音）と、単語帳から音ごとに集めた単語 |
| `GrammarSeed.swift` | 文法の項目（入門〜上級）。`tools/grammar/topics.py` を編集して `python3 tools/grammar/build.py` で再生成（発音記号は espeak-ng） |
| `GrammarMCQSeed.swift` | 4択の練習問題 |

トピック会話は `tools/topics/*.txt` が元データで、`python3 tools/topics/build.py` で `SeedData.swift` に書き込まれます。

## 復習のしくみ

- 新しい単語は「1日後」の段階から始まります。
- **思い出せた** → 次の段階へ（1日後 → 1週間後 → 2週間後 → 1ヶ月後 → 習得）。
- **思い出せなかった** → 「1日後」に戻り、翌日にもう一度。
- 学習の記録は端末内（Documents/englishvocab_library.json, englishvocab_stats.json）に保存されます。収録単語は進捗だけを保存し、内容は保存しません。
