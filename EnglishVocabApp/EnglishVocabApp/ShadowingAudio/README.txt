シャドウイング用の音声フォルダです（Xcode では青いフォルダ＝そのまま同梱）。

シャドウイングの文は、すべて元の録音の音声で再生します（iPhone の読み上げ音声は使いません）。
通常は、アプリの 発音 → シャドウイング →「音声ファイルを取り込む」で自分の録音を取り込みます
（端末の中だけに保存され、このフォルダには入りません）。

文ごとに切り出した音声をアプリに同梱する場合だけ、ここに置きます。
  shadow_s31.m4a  … 文 s31 の音声（m4a / mp3 / wav / caf）
  shadow_s31.json … 任意。各単語の開始時刻（秒）の配列
文の一覧と ID は tools/shadowing/sentences.py を参照。
